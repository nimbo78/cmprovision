# 2.30.13 — Автоопределение GPIO-дисплея 🖥️

- **Определение экрана при загрузке.** Универсальный образ станции распознаёт Waveshare 1,44″ или прямоугольный HyperPixel 4.0 Touch. Waveshare начинает работать в ту же загрузку. Для HyperPixel свободная станция один раз перезапускается, чтобы включить профиль. Закреплённые профили дисплея и режим Off сохраняют своё поведение. [Настройка экрана](https://github.com/nimbo78/cmprovision/blob/v2.30.13/docs/ru/fpms-display.md)
- **Установка FPMS Lite при наличии поддерживаемого экрана.** На свободной станции Auto может установить `fpms-lite` нужной версии из подписанного релиза и запустить панель. [Автоматический запуск экрана](https://github.com/nimbo78/cmprovision/pull/46)

Автоматический запуск HyperPixel после холодного старта проверен на wlanpi-d62. Проверки физической замены панели и автоустановки пакета на станции без FPMS Lite ещё предстоят.

Работающую станцию можно обновить через **Settings → Updates → Application**. Для новой станции используйте готовый образ ARM64. Если профиль уже закреплён, перед заменой экрана переведите станцию в Auto по инструкции дисплея. [Инструкция по обновлению](https://github.com/nimbo78/cmprovision/blob/v2.30.13/docs/ru/upgrading.md)
