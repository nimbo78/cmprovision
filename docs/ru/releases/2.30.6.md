# 2.30.6 — Восстановление после обрыва питания 🔌

## Когда питание вернулось

Перед установкой станция запоминает, какие службы загрузки работали. При следующем включении DHCP/TFTP и загрузка по USB ждут завершения восстановления. Затем основная станция снова может принимать платы, а на вторичной сохраняется блокировка запуска этих служб. Защита действует для операций, начатых обновлятором версии 2.30.6.

## Перед установкой

В **Settings → Updates → Review and apply** видно, сколько места нужно и сколько свободно на каждой файловой системе. При нехватке места стенд продолжает прошивать платы. Перед откатом обновлятор также проверяет выбранный снимок, содержимое архивов, версии пакетов и роль станции. Загруженные образы по-прежнему входят в снимок приложения. [Место на диске и восстановление](https://github.com/nimbo78/cmprovision/blob/v2.30.6/docs/ru/updates.md)

## Что видно в журнале

При ручном откате станция также сверяет наличие пакета дисплея FPMS с выбранной копией. Если состав пакетов или роль станции изменились, предупреждение появится, пока стенд ещё доступен для работы.

После установки страница обновляет номер версии и убирает предложение поставить тот же выпуск. Если позже пропадёт связь с издателем, в журнале останутся сообщение об ошибке и время последней успешной проверки.

На действующем провижинере откройте **Settings → Updates → Application**. Для новой станции запишите образ Lite для ARM64 из файлов выпуска. [Инструкция по установке](https://github.com/nimbo78/cmprovision/blob/v2.30.6/docs/ru/upgrading.md)
