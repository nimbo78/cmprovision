# 2.30.11 — Полное восстановление после перепрошивки 🛟

При восстановлении полной копии на той же станции выберите группу `network`, чтобы вернуть профили NetworkManager. Если VLAN 15 был настроен на `eth0`, для предварительного просмотра достаточно самого `eth0`. При применении копии NetworkManager загружает профиль VLAN и поднимает интерфейс, если включено автоподключение.

Восстановление использует установленный `cmprovision4` той же версии, что и в архиве, если `dpkg` обнаружил изменения только в конфигурации сайта nginx или dnsmasq, которую настраивает установщик. При пропавших файлах и других расхождениях по-прежнему требуется восстановление пакета. Из копии также возвращается обычно пустой каталог `storage/app/public`, чтобы следующая проверка пакета прошла успешно. [Инструкция по полным бэкапам](https://github.com/nimbo78/cmprovision/blob/v2.30.11/docs/ru/backups.md)

В изолированном Debian прошли предварительный просмотр и полное восстановление. NetworkManager вернул VLAN 15 с исходными UUID и IP-адресом. На физической станции `wlanpi-d62` проверка приняла её реальный профиль VLAN и настройки пакета. [Журнал проверки](https://github.com/nimbo78/cmprovision/actions/runs/44971618503/job/137052571117)

Для обновления станции откройте **Settings → Updates → Application**. Для чистой установки используйте образ ARM64 из файлов выпуска. [Руководство по обновлению](https://github.com/nimbo78/cmprovision/blob/v2.30.11/docs/ru/upgrading.md)
