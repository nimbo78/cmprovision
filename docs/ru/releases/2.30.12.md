# 2.30.12 — Время для сети прошивки и распознавание сенсоров соседней станции 🕒

- **NTP в сети прошивки.** В **Settings → System → Time and synchronization** можно включить раздачу времени на подтверждённом интерфейсе или VLAN прошивки. Основная станция передаёт свой адрес сенсорам, запросившим опцию DHCP 42. По умолчанию раздача выключена. В готовом образе уже есть chrony. У действующей станции при обновлении сохраняется прежняя служба времени. Перейти на chrony можно во время обслуживания. [Настройка времени](https://github.com/nimbo78/cmprovision/blob/v2.30.12/docs/ru/system-time.md)
- **Статус OURS после прошивки на соседнем стенде.** Ports, HDMI и FPMS показывают, кто прошил сенсор, если подпись метки подтверждена и соответствует единственному MAC на порту. Прежний локальный прогон сохраняется в CMs. У выполняющейся локальной прошивки остаётся приоритет. На Cisco IOS с несколькими VLAN прошивки выберите в настройках коммутатора чтение таблицы MAC по VLAN. [Распознавание сенсоров](https://github.com/nimbo78/cmprovision/blob/v2.30.12/docs/ru/operations.md)
- **Установка пакета экрана из веб-интерфейса.** На стабильной версии кнопка **Settings → System → FPMS display → Install fpms-lite** устанавливает пакет из подписанного релиза той же версии. Станция должна быть свободна, действие требует подтверждения пароля. После установки экран можно включить в той же карточке. [Настройка FPMS](https://github.com/nimbo78/cmprovision/blob/v2.30.12/docs/ru/fpms-display.md)

На стенде с CM4 сенсор в VLAN 62 получил адрес сервера времени по DHCP и запросил у станции время. Соседний провижинер показал этот сенсор как **OURS** на порту 3, а на порту 1 сохранил статус своей завершённой прошивки.

Действующую станцию можно обновить через **Settings → Updates → Application**. Для новой станции используйте образ ARM64 из файлов выпуска. [Инструкция по обновлению](https://github.com/nimbo78/cmprovision/blob/v2.30.12/docs/ru/upgrading.md)
