# 2.30.14 — USB-консоль, администраторы станции и карта коммутатора 🔌

- **USB-консоль из браузера.** Подключите поддерживаемый адаптер и откройте **Console** рядом с **Ports**. Оператор с доступом к консоли выбирает кабель, подтверждает веб-пароль и открывает терминал. Режим Auto подбирает скорость и формат кадра. Для молчащего устройства можно включить однократную отправку Enter при подключении кабеля в веб-консоли. Длинную конфигурацию можно отправить файлом или вставить из буфера и следить за ответом на каждую команду. При отказе команды или запросе, требующем участия оператора, передача приостанавливается. [Инструкция по USB-консоли](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/ru/serial-console.md)
- **Второй администратор станции.** В **Settings → System** можно создать учётную запись Linux и разрешить ей вход по SSH с паролем. Перед применением станция запросит локальное подтверждение. Новый вход удобно проверить во втором терминале, пока первый сеанс открыт. [Доступ к станции](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/ru/station-setup.md)
- **Порты Huawei на своих местах.** Карта S5735I-S8U4XN-V2 показывает четыре гнезда 10G SFP+ над восемью портами 1G RJ45 с PoE. Недоступный коммутатор занимает одну строку и пропускается при перелистывании. На проверенной прошивке Huawei медные порты подавали питание, но коммутатор не отдавал показания мощности по SNMP. [Передние панели коммутаторов](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/ru/switch-front-panels.md)
- **Переподключение HDMI и запуск Waveshare.** На d62 после переподключения телевизора графическое табло вернулось в режиме 1080p60, а HyperPixel продолжил работать. На da2 после холодного старта режим Auto распознал Waveshare, меню листалось джойстиком. [HDMI](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/ru/hdmi-display.md) · [GPIO-дисплеи](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/ru/fpms-display.md)

Установить обновление на работающую станцию можно через **Settings → Updates → Application**. Для новой станции в выпуске есть готовый образ ARM64. [Инструкция по обновлению](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/ru/upgrading.md)
