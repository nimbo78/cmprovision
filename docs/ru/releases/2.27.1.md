# 2.27.1 — Возврат после обновления и аккуратные настройки 🔧✨

## Что изменилось

- После планового обновления станции окно ошибки Livewire больше не остаётся поверх успешного результата.
  Страница показывает ход операции, восстанавливает связь после запуска веб-службы и обновляет установленную версию.
  Ошибки входа, истёкшие сессии и неожиданные ошибки сервера обрабатываются как раньше.
- Состояния служб и кнопки их журналов находятся в **Settings → Status**.
  Network, Provisioning, Notifications и Updates больше не повторяют полосу служб и меню Logs.
  Открытие этих вкладок также не опрашивает полный список серверных служб.
- Сохранены имена служб для FPMS, подтверждение обновления, проверка простоя, копия для восстановления и автоматический откат.

## Проверка и область изменений

Полный локальный прогон PHP завершился без ошибок: **2190 тестов, 8481 проверка, 27 пропусков и одно прежнее замечание PHPUnit**.
Все **84 теста JavaScript** пройдены. В браузере проверены пять вкладок настроек на ширине 1920 и 390 пикселей,
настоящий ответ HTTP о режиме обслуживания, имитация обрыва соединения и автоматический возврат к успешному результату без перезагрузки страницы.
При посторонней ошибке сервера обычное окно ошибки сохраняется. Независимое ревью не нашло замечаний, требующих исправления.

Устанавливайте через **Settings → Updates** на свободном стенде. Приложение обновляется вместе с установленным FPMS Lite;
выбранная утилитарная ОС и прежние состояния служб сохраняются. Новая миграция базы не добавляется.
Полный процесс выпуска собирает и проверяет оба пакета и образ ARM64, подписывает метаданные обновления
и перед публикацией сверяет хеши всех загруженных файлов.

Образ станции остаётся **экспериментальным**, FPMS — **предварительной функцией**. Этот патч не заменяет аппаратную приёмку.
