# Создать проект, этикетку или скрипт через мастер

[Эксплуатация](operations.md) · [Перенос конфигурации](configuration-transfer.md)

На **Projects**, **Labels** и **Scripts** есть **Create with wizard**. **Copy with wizard** начинает с существующей записи и создаёт отдельный объект. Обычные формы **Add** и **Edit** остаются доступны.

Мастер показывает этапы, проверяет текущий шаг перед переходом и предлагает Back, Cancel и итоговую проверку. Back сохраняет введённое. Save доступна только в конце и повторно проверяет определение целиком. Escape отменяет мастер.

## Проекты

1. Выберите имя и назначение: прошивка сенсоров или настройка новой станции cmprovision.
2. Выберите образ и накопитель. Для eMMC CM4 обычно нужен `/dev/mmcblk0`. Проект сенсора может обходиться без образа ради скриптов или EEPROM; настройка станции требует образ.
3. Выберите проверку записи, OS check, докачку по частям, доступ re-provision, срок метки и при необходимости обновление EEPROM.
4. Выберите скрипты и пакеты первого запуска. First-boot скрипты и пакеты требуют OS check. Скрипты с меньшим приоритетом запускаются раньше.
5. Выберите этикетку и момент печати. Для печати с именем хоста установленной системы нужен OS check.
6. Для проекта станции задайте Linux-пользователя, пароль или SSH-ключи и при необходимости управляющую Wi-Fi-сеть. Нужен совместимый [образ станции](station-project-setup.md).
7. Проверьте итог и сохраните. Выбирайте **Set as active project**, только если проект нужно активировать сразу.

Новый проект мастера начинает с включёнными Verify, OS check и Split; активация и Re-provision выключены. Обычная полная форма сохраняет свои прежние умолчания.

Verify сверяет записанные данные с хешем образа. OS check загружает установленную систему и выполняет работу первого запуска. Split позволяет продолжить прерванную запись с последней завершённой части. Re-provision устанавливает ограниченный агент доступа станции; срок метки определяет число загрузок с проверяемой меткой провижининга. Подписи полей объясняют требования.

Копия проекта сохраняет зависимости и порядок скриптов, получает новое имя и ID и остаётся неактивной до явного выбора. Пароли станции остаются приватными при Back/Next; сохранённый Wi-Fi-пароль используется только для той же SSID.

## Этикетки

Выберите имя, расширение файла и способ печати, затем настройте команду или FTP. Отредактируйте шаблон и проверьте экранированный пример с теми же данными, что используются для тестовой печати:

| Переменная | Пример |
| --- | --- |
| `$serial` | `1000000012345678` |
| `$mac` | `11:22:33:44:55:66` |
| `$hostname` | `wlanpi-a1b` |
| `$provisionboard` | `sw01 Gi0/3` |
| `$switch` | `sw01` |
| `$port` | `Gi0/3` |

Копирование рабочей этикетки сохраняет язык принтера и разметку. Пример показывает подстановку переменных, а не графическое изображение принтерных команд.

В конце **Print test label** явно обращается к принтеру или запускает команду. **Save** только сохраняет определение. Скопированный FTP-пароль хранится приватно и используется лишь для тех же хоста и пользователя; при изменении любого из них нужен новый пароль.

## Скрипты

Выберите имя, фазу, приоритет и фоновое выполнение, затем содержимое. Новый скрипт начинается с `#!/bin/sh` и `set -e`.

- **Pre-install:** утилитарная ОС до записи образа.
- **Post-install:** после записи, с разделами образа в `$PART1` и `$PART2`.
- **First boot:** от root в установленной ОС во время её проверки; ненулевой код завершения проваливает проверку. Эти скрипты всегда выполняются последовательно.

Back сохраняет текст. Save нормализует окончания строк и сохраняет определение, не выполняя его. Копирование сохраняет текст, фазу и приоритет, создавая новую запись.

## Приватное состояние и перенос

Пароли мастер передаёт аргументами действий и хранит зашифрованными в сессии вошедшего пользователя, вне снимка Livewire. Приватное состояние действует 24 часа и удаляется при Save или Cancel. Завершайте мастер в той же сессии; перезагрузка страницы не открывает незавершённую форму.

После сохранения откройте **Settings → Status → Backup → Selective import / export** и выберите объект для [переноса конфигурации](configuration-transfer.md). Общие проверки используются мастерами, полными формами и импортом. Перенос включает зависимости, отдельно предлагает защиту секретов и оставляет импортированные проекты неактивными.
