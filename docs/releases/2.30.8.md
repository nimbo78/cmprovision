# 2.30.8 — Touch dashboard for HyperPixel 4.0

## Follow a batch from the stand

On the rectangular **HyperPixel 4.0 Touch**, tap a counter on **Overview** to see the modules in that state. Tap a device for diagnostics. **Back** returns to the same place in the list.

- **Ports** shows Ethernet link and PoE separately. A port can still supply power after the link goes down. **Connected** lists device names and measured watts.
- **Station** shows the management address, Wi-Fi signal and transmit rate, or wired link speed. Health badges name stopped and disabled services and show free disk space.
- Set the idle timeout from **Settings → System → FPMS display** or directly on a HyperPixel or Waveshare panel. The first tap on a sleeping HyperPixel wakes it.

## Install or update

On an existing station, choose **Settings → Updates → Application**. The updater includes the matching `fpms-lite` package when it is already installed. When fitting a HyperPixel, enable its DPI boot profile and install `python3-kms++`. The ARM64 station image with FPMS includes that dependency. [Display setup and controls](https://github.com/nimbo78/cmprovision/blob/v2.30.8/docs/fpms-display.md#hyperpixel-40-touch)

On a CM4 station with a Mcuzone Wi-Fi 7 board, the GT911 passed three-point touch calibration. The five tabs, **Done** filter and an empty port were checked on the running 800 × 480 panel. Simultaneous use with an HDMI wallboard is tracked separately.
