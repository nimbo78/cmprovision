# 2.30.1 — One verified copy, less disk pressure 📦🧹

## What changed

- Package snapshots retain one completed copy per destination. Legacy keep counts and `all` no longer raise the cap; unfinished copies and unrelated files remain protected.
- The updater retains one recovery point across application and Utility OS updates. Idle migration and cleanup before snapshot space checks reclaim obsolete owned copies while protecting active recovery and rollback sources.
- Full backups retain one verified remote copy per station/destination, one available browser archive and one recorded pre-restore recovery copy. Previous usable copies survive failed replacements. Legacy settings normalize to one, and retention-count fields are removed.
- Snapshot creation/pruning is serialized, and an active package restore locks its source through nested package hooks. Archive ownership survives the 50-summary UI history window.
- A verified remote publication is committed before service cleanup. Interrupted cleanup resumes retention without uploading again; cancellation after publication does not undo the completed copy.

## Verification and limits

Local verification passed 2239 PHP tests / 8848 assertions, 90 JavaScript tests, 79 updater tests and 88 backup tests. Six optional external-storage tests were skipped; the PHP suite retained three warnings and 27 environment-dependent skips. Actual backup/restore scripts passed isolated station-role and network-gate integration checks. The CSS rebuild is unchanged. Independent review findings were fixed and reproduced successfully.

No database migration is added. Installation applies a smaller retention policy: removed historical archives cannot be recovered by downgrading the package. Active recovery and verified replacement may temporarily require additional space. Unknown/operator files and unrelated remote objects are preserved. Remote delete failures report a warning; power loss before the local ownership receipt can leave an unrecorded remote object requiring manual inspection.

The changes have not yet been installed on wlanpi-da2 or wlanpi-d62. FPMS remains preview; the station image remains experimental. Publication is gated on release CI building and verifying both packages, the station image, checksums and signed update metadata.
