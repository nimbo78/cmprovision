# 2.30.13 — Automatic GPIO display setup 🖥️

- **Detect the panel at startup.** A universal station image detects the Waveshare 1.44-inch or rectangular HyperPixel 4.0 Touch. Waveshare starts in the same boot. An idle station restarts once to load the HyperPixel profile. Existing fixed display profiles and the Off setting retain their behavior. [Display setup](https://github.com/nimbo78/cmprovision/blob/v2.30.13/docs/fpms-display.md)
- **Install FPMS Lite when a supported panel is present.** On an idle station, Auto can install the matching `fpms-lite` package from the signed release and start the panel. [Automatic display setup](https://github.com/nimbo78/cmprovision/pull/46)

The automatic HyperPixel profile was checked on wlanpi-d62 after a cold boot. Physical panel replacement and automatic installation on a station without FPMS Lite are pending.

Update an existing station through **Settings → Updates → Application**. For initial setup, use the ARM64 station image. Owners of a station with a fixed profile can follow the display guide to switch it to Auto before changing panels. [Upgrade guide](https://github.com/nimbo78/cmprovision/blob/v2.30.13/docs/upgrading.md)
