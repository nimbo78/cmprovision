# 2.30.2 — Seven-day recovery, room for the next update 🕒🧹

## What changed

- The updater keeps one recovery point for seven days after successful completion. Later metadata changes do not extend the deadline. Expired points are removed when the station is idle, including by the existing hourly timer even when publisher auto-checks are disabled.
- Before creating the next application snapshot, the updater retires the previous eligible point, checks free space and then captures the new snapshot. This prevents an old retained archive from blocking preparation of its replacement.
- Active or critical recovery and the selected source of an ongoing rollback remain protected. Temporary file-deletion failures are retried during later idle housekeeping.
- Settings and the English/Russian update guides explain the policy. Ordinary package snapshots and manual/full backups retain their separate policies.

## Verification and limits

PR #27 passed all eight CI checks, including 86 updater tests, all 94 backup/remote-storage tests, real Debian package installation, manual/automatic rollback, interrupted-install recovery and full restore/failure acceptance. CI PHP passed 2235 tests / 8830 assertions with three warnings and 34 environment-dependent skips. Local verification passed 2242 PHP tests / 8856 assertions and 90 JavaScript tests. Independent review findings were fixed and verified; the CSS rebuild is unchanged.

There is no database migration. Starting a new snapshot deliberately removes the old eligible recovery point before free-space validation and capture: if preparation then fails, that old rollback is unavailable. Deleted archives cannot be restored by downgrading the package. Unknown files and active recovery remain protected; an expired point is reclaimed on the next idle housekeeping run, rather than at an exact wall-clock instant.

Hardware acceptance on wlanpi-d62, followed by wlanpi-da2, is performed after signed publication. FPMS remains preview and the station image remains experimental. Release CI must build and verify both packages, the station image, checksums and signed update metadata before publication.
