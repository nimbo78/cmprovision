# 2.30.12 — Time for the stand, recognition across stations 🕒

- **NTP for the provisioning network.** In **Settings → System → Time and synchronization**, enable serving on the confirmed provisioning interface or VLAN. A primary station advertises its address to sensors requesting DHCP option 42. Serving starts disabled. Fresh station images include managed chrony. Existing stations keep their time provider on upgrade and can switch to chrony during maintenance. [Time and synchronization](https://github.com/nimbo78/cmprovision/blob/v2.30.12/docs/system-time.md)
- **OURS after a peer reflash.** Ports, HDMI and FPMS identify the station that flashed a sensor when its signed mark matches the single MAC learned on the port. An earlier local run stays in CMs. A running local job still has priority. For Cisco IOS stands spanning several provisioning VLANs, select the per-VLAN MAC table in switch settings. [Recognizing sensors](https://github.com/nimbo78/cmprovision/blob/v2.30.12/docs/operations.md)
- **Install the front-panel package from the web.** On a stable release, **Settings → System → FPMS display → Install fpms-lite** installs the display package from the matching signed release. The action requires an idle station and password confirmation. Enable the display from the same card after installation. [FPMS display](https://github.com/nimbo78/cmprovision/blob/v2.30.12/docs/fpms-display.md)

On the CM4 stand, a sensor on VLAN 62 received the time server address over DHCP and queried the station. The neighboring provisioner showed the peer-flashed sensor as **OURS** on port 3 and its own completed sensor on port 1.

Existing stations can update through **Settings → Updates → Application**. For a new station, use the ARM64 image attached to this release. [Upgrade guide](https://github.com/nimbo78/cmprovision/blob/v2.30.12/docs/upgrading.md)
