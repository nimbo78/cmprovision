# 2.30.14 — USB console, station accounts and switch displays 🔌

- **Open a USB console from the browser.** Connect a supported adapter and open **Console** beside **Ports**. Operators with console access can select the cable, confirm their web password and open the terminal. Auto checks baud rate and framing. For a quiet device, enable one Enter when opening that cable in the web console. For long configurations, send a file or paste several lines and follow the response to each command. Transfers pause on a rejected command or a prompt that needs an operator. [USB console guide](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/serial-console.md)
- **Add a second station administrator.** In **Settings → System**, create a Linux account and, if needed, enable SSH password login for that user. The station asks for local approval before applying the change. Use a second terminal to verify the new login while your current session is open. [Station access](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/station-setup.md)
- **Find the physical port on the Huawei switch.** The S5735I-S8U4XN-V2 map shows four 10G SFP+ cages above eight 1G RJ45 PoE ports. Offline switches occupy one row and are skipped during rotation. On the tested Huawei firmware, the copper ports supplied power but SNMP did not return wattage. [Switch front panels](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/switch-front-panels.md)
- **Reconnect a monitor or cold-start a GPIO panel.** On d62, the graphical HDMI wallboard returned at 1080p60 after reconnecting the TV while HyperPixel stayed active. On da2, Auto detected Waveshare at cold boot and joystick navigation worked. [HDMI](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/hdmi-display.md) · [GPIO displays](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/fpms-display.md)

Update a running station through **Settings → Updates → Application**. For a new station, use the ARM64 image from this release. [Upgrade guide](https://github.com/nimbo78/cmprovision/blob/v2.30.14/docs/upgrading.md)
