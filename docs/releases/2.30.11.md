# 2.30.11 — Full restore after reimaging 🛟

When restoring a full backup to the same station, select the `network` group to bring back its NetworkManager profiles. If VLAN 15 was configured on `eth0`, only `eth0` needs to exist for preview. On apply, NetworkManager loads the saved VLAN profile and follows its autoconnect setting.

Restore can reuse an installed `cmprovision4` package of the archived version when the only differences reported by `dpkg` are the nginx site or dnsmasq configuration customized by the installer. Missing files and other reported changes still require package recovery. Restore also recreates the normally empty `storage/app/public` directory, so the next package check succeeds. [Full backup and restore guide](https://github.com/nimbo78/cmprovision/blob/v2.30.11/docs/backups.md)

The complete preview and restore ran on an isolated Debian station. NetworkManager recreated VLAN 15 with its original UUID and IP address. On physical `wlanpi-d62`, the checks accepted its actual VLAN profile and package configuration. [Acceptance run](https://github.com/nimbo78/cmprovision/actions/runs/44971618503/job/137052571117)

For an existing station, open **Settings → Updates → Application**. For a fresh installation, use the ARM64 station image attached to this release. [Upgrade guide](https://github.com/nimbo78/cmprovision/blob/v2.30.11/docs/upgrading.md)
