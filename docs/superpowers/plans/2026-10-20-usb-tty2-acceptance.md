## До включения сенсора

- [ ] Проверить отсутствие активных прошивок и свежие serial/MAC/порт сенсора.
- [ ] Сверить carrier с таблицей BOOT/OTG; определить USB-C programming, не AUX.
- [ ] Убедиться, что выбран нужный проект и Utility OS 2026.10.
- [ ] Собрать USB или HDMI/клавиатуру по соответствующей пользовательской статье.

## tty2

- [ ] На выключенном сенсоре подключить HDMI и клавиатуру, BOOT разомкнут, Host включён.
- [ ] Запустить штатный сетевой re-provision этого сенсора с проектом stage1-test.
- [ ] На клавиатуре сенсора Alt+F2, вход root с пустым паролем.
- [ ] Зафиксировать `/dev/tty2`, 2026.10, `6.18.50-cmprovision`, `aarch64`, serial и IP eth0.
- [ ] Alt+F1/Alt+F2 переключают вывод и консоль, запись продолжает идти.
- [ ] Сетевая запись, SHA256 и OS check завершились успешно; итог Done.

Пока не получены результаты, ручные пункты остаются незавершёнными. Отсутствие
кабеля или наблюдения не считается успешным тестом. Перед выпуском явно записать
результат каждого пункта, исправления и повторные проверки при необходимости.
Только после успешного завершения согласованной матрицы — версия 2.7.0,
интеграция веток, тег, окончательный пакет и публикация исходников/лицензий.
