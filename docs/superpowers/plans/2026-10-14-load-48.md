# 48 модулей разом (2.5.0) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** провижинер выдерживает волну 40–48 модулей, стартующих разом: скрипт сразу, плата через секунды, отчёты доходят, уведомления пачками в лимитах, одна партия на волну, EEPROM не обесточивается.

**Architecture:** свой пул php-fpm и SQLite в WAL дают запас мощности; поиск платы уходит из запроса старта в задачу очереди `ResolveBoards` (один опрос стенда на волну); уведомления пишутся в таблицу `notification_outbox` и отправляются задачей `FlushNotifications` пачками раз в окно; партия выбирается под замком; `PoeRestart` перед выключением порта перечитывает из базы, не пишет ли модуль порта EEPROM.

**Tech Stack:** PHP 8.3+ (тесты на 8.4), Laravel 13.35 (раскладка Laravel 8), Livewire 3, SQLite, очередь `database`, Debian-пакет (debhelper 13), php-fpm, nginx, snmpsim на стенде WSL.

**Spec:** `docs/superpowers/specs/2026-10-14-load-48-design.md`

## Global Constraints

- Пул php-fpm: секция `[cmprovision]`, `listen = /run/php/cmprovision-fpm.sock`, `pm = dynamic`, `pm.max_children = 16`, `pm.start_servers = 4`, `pm.min_spare_servers = 2`, `pm.max_spare_servers = 6`, `pm.max_requests = 500`; файл `/etc/php/<версия>/fpm/pool.d/cmprovision.conf` пишет `postinst`; `www.conf` не трогается; `postrm purge` удаляет файл пула.
- Сайт nginx — conffile, который правит `postinst`: `debian/cmprovision` не меняется (изменённая поставляемая копия остановила бы обновление вопросом dpkg о conffile), сокет `cmprovision-fpm.sock` вписывает `postinst`.
- SQLite: `'busy_timeout' => 5000`, `'journal_mode' => 'wal'`, `'synchronous' => 'normal'`.
- root не открывает базу: artisan в `postinst` и `tools/restore.sh`, `sqlite3` в `tools/backup.sh` работают от www-data (`runuser -u www-data --`).
- Очереди: `cmprovision-queue` — `--queue=boards,notifications`; `cmprovision-queue-images` — `--queue=boards,images,default` (платы первыми и здесь: медленный чат-сервер не задерживает плату; `default` — задачи, оставшиеся от 2.4); `ComputeSHA256` — очередь `images`.
- `ResolveBoards` и `FlushNotifications` — `ShouldBeUniqueUntilProcessing`. Следующий прогон задача ставит сама (`self::dispatch()->delay(…)`), а не `release()`: так в очереди ждёт не больше одного прогона (в Laravel 13 отпущенная `release()` задача замок не держит). Синхронная очередь тестов следующего прогона не ставит.
- Плата: повтор через `ResolveBoards::RETRY_SECONDS = 3` с, отказ через `GIVE_UP_SECONDS = 60` с от `board_pending_since`; событие `CmProvisioningStarted` остаётся в запросе старта; модуль, отказанный на старте, получает плату, но не этикетку (как до 2.5).
- Уведомления: окно `FlushNotifications::WINDOW = 10` с; между вызовами к одному чату (бот или Mattermost webhook) не меньше 1 с, JSON webhook — без паузы; 429 → следующий прогон через `retry_after`, канал до того не трогается; ошибка → повтор через 30 с, не больше 5 попыток; сообщение длиннее 4000 символов делится по строкам; адрес Bot API — `config('cmprovision.telegram_api')`, переменная `TELEGRAM_API`, по умолчанию `https://api.telegram.org`; кнопка Test остаётся синхронной.
- Партия: замок `notification-batch`, 10 с, ожидание 5 с.
- Секреты в браузер не уходят; токен Telegram вырезается из ошибок (`Notifier::redact()`).
- Версия `2.5.0~dev1`; `preinst` снимает снимок при обновлении с версии ниже `2.5.0~`.
- Код и строки интерфейса — по-английски, как в проекте; комментарии — в стиле соседнего кода.
- Коммиты кончаются строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; выпуск, слияние, пуш и установка на провижинер — только по слову пользователя.

    /* The batch a starting module joins: the open one of this project, or a new one. 40-48 modules start at once:
       one of them chooses under the lock, the others wait and join it (after 5 s they choose anyway) */
    public static function current(Project $project)
    {
        try
        {
            return Cache::lock('notification-batch', 10)->block(5, function () use ($project) {
                return self::choose($project);
            });
        }
        catch (LockTimeoutException $e)
        {
            return self::choose($project);
        }
    }

    protected static function choose(Project $project)
    {
        $batch = self::whereNull('closed_at')->latest('id')->first();
        if ($batch && ($batch->project_id != $project->id || $batch->last_event_at->lt(now()->subHours(self::IDLE_HOURS))))
        {
            $batch->update(['closed_at' => now()]);
            $batch = null;
        }

        return $batch ?: self::create(['project_id' => $project->id, 'started_at' => now(), 'last_event_at' => now()]);
    }

/* A module's label as its project prints it: FTP to the printer, or a command with the label in a file. What goes
   wrong, or what the command says, lands in the module's log; $ip is the module's address when it asked */
class LabelPrinter

    public static function print(Cm $cm, ?string $ip = null): void
    {
        $labelsettings = $cm->project ? $cm->project->label : null;
        if (!$labelsettings)
            return;
        $label = str_replace('$mac', $cm->mac, $labelsettings->template);
        $label = str_replace('$serial', $cm->serial, $label);
        // the board ("sw01 Gi0/3") and its two halves; empty without a switch
        $label = str_replace(['$provisionboard', '$switch', '$port'],
            [(string) $cm->provisioning_board, (string) $cm->switch_name, (string) $cm->switch_port], $label);
        $tmpfile = tempnam(sys_get_temp_dir(), "label-");

        try
        {
            if (!@file_put_contents($tmpfile, $label))
                throw new \Exception("Error creating temporary file for label '$tmpfile'");

            if ($labelsettings->printer_type == 'ftp')
            {
                $ftp = @ftp_connect($labelsettings->ftp_hostname);
                if (!$ftp)
                    throw new \Exception("Error connecting to printer's FTP server ".$labelsettings->ftp_hostname);
                if (!@ftp_login($ftp, $labelsettings->ftp_username, $labelsettings->ftp_password))
                    throw new \Exception("Error logging in to printer's FTP server. Check username and password");
                @ftp_pasv($ftp, true);
                if (!@ftp_put($ftp, "label-".$cm->serial.".".$labelsettings->file_extension, $tmpfile))
                    throw new \Exception("Error uploading file to printer's FTP server");
                @ftp_close($ftp);
            }
            else if ($labelsettings->printer_type == 'command')
            {
                $cmd = str_replace('$file', escapeshellarg($tmpfile), $labelsettings->print_command);
                $output = $retcode = null;
                // stderr too: sh reports a file it cannot write there; the newline survives a trailing comment
                if (@exec('{ '.$cmd."\n} 2>&1", $output, $retcode) === false)
                    throw new \Exception("Error executing '$cmd'");
                if ($retcode)
                    throw new \Exception("Executing '$cmd' returned exit code $retcode. Program output:\n".implode("\n", $output));
                // a command can report trouble and still exit 0 (a CSV it cannot write): keep what it said
                $said = trim(implode("\n", $output));
                if ($said !== '')
                    self::log($cm, $ip, 'info', 'Label command output: '.$said);
            }
        }
        catch (\Exception $e)
        {
            self::log($cm, $ip, 'error', $e->getMessage());
        }
        @unlink($tmpfile);
    }

    protected static function log(Cm $cm, ?string $ip, string $level, string $msg): void

namespace App\Jobs;

use App\Models\Cm;
use App\Models\Cmlog;
use App\Services\LabelPrinter;
use App\Services\Switch\PortLookup;
use App\Services\Switch\Stand;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldBeUniqueUntilProcessing;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\Jobs\SyncJob;

/* The boards of the modules whose start waits for one (cms.board_pending_since): one poll of the stand for all of
   them, the 2.4 rules for each MAC (PortLookup::resolve). A module not on the map yet is looked up again
   RETRY_SECONDS later; after GIVE_UP_SECONDS it gets no board and the warning. Unique until a worker takes it: a
   start during a run queues the next run, and one run at a time waits in the queue. Runs may overlap (both workers
   take boards): settle() records each module once, and whoever records it prints the preinstall label */
class ResolveBoards implements ShouldQueue, ShouldBeUniqueUntilProcessing
{
    use Dispatchable, InteractsWithQueue, Queueable;

    const RETRY_SECONDS = 3;
    const GIVE_UP_SECONDS = 60;

    public $uniqueFor = 120;

    public function __construct()
    {
        $this->onQueue('boards');
    }

    public function handle(): void
    {
        $pending = Cm::whereNotNull('board_pending_since')->orderBy('board_pending_since')->get();
        if ($pending->isEmpty())
            return;
        // a snapshot taken after the latest start; a later run asks for a newer one than the run before it saw
        $notOlderThan = max($pending->max('board_pending_since')->getTimestamp(), now()->getTimestamp() - 1);
        $trouble = null;
        try
        {
            $stand = Stand::current($notOlderThan, PortLookup::WAIT);
        }
        catch (\Throwable $e)
        {
            $stand = null;
            $trouble = 'Switch port unknown: '.$e->getMessage();
        }

        $waiting = false;
        foreach ($pending as $cm)
        {
            $found = $stand ? PortLookup::resolve($stand, $cm->mac)
                            : ['switch' => null, 'port' => null, 'board' => null, 'warning' => $trouble];
            $late = now()->getTimestamp() - $cm->board_pending_since->getTimestamp() >= self::GIVE_UP_SECONDS;
            // no switch left since the start: nothing to wait for
            if ($found['board'] === null && ($stand || $trouble) && !$late)
            {
                $waiting = true;
                continue;
            }
            self::settle($cm, $found);
        }
        // the sync queue of the tests runs a dispatch at once: no next run there
        if ($waiting && !$this->job instanceof SyncJob)
            self::dispatch()->delay(now()->addSeconds(self::RETRY_SECONDS));
    }

    /** Record what the lookup found for this start of the module; false when the module started again meanwhile or
        another run recorded it first. A module refused at its start (failed by now) gets no label, as before 2.5 */
    public static function settle(Cm $cm, array $found): bool
    {
        $recorded = Cm::whereKey($cm->id)->where('board_pending_since', $cm->board_pending_since)->update([
            'provisioning_board' => $found['board'],
            'switch_id' => $found['switch']->id ?? null,
            'switch_name' => $found['switch'] ? $found['switch']->hostname() : null,
            'switch_port' => $found['port'],
            'board_pending_since' => null,
        ]);
        if (!$recorded)
            return false;
        $cm->refresh();
        if ($found['warning'])
            Cmlog::create(['cm' => $cm->serial, 'board' => $cm->provisioning_board, 'loglevel' => 'warning', 'msg' => $found['warning']]);
        if ($cm->phase !== 'failed' && $cm->project && $cm->project->label_moment === 'preinstall' && $cm->project->label)
            LabelPrinter::print($cm);
        return true;
    }
}

<?php

namespace App\Jobs;

use App\Models\NotificationChannel;
use App\Models\NotificationOutbox;
use App\Services\Notifier;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldBeUniqueUntilProcessing;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Foundation\Bus\Dispatchable;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\Jobs\SyncJob;

/* Sends what notification_outbox holds (Notifier::flush): a chat gets one pack per WINDOW seconds, a JSON webhook a
   request per event. Unique until a worker takes it: the events of a window join the run that waits for it */
class FlushNotifications implements ShouldQueue, ShouldBeUniqueUntilProcessing
{
    use Dispatchable, InteractsWithQueue, Queueable;

    const WINDOW = 10;

    public $uniqueFor = 600;

    public function __construct()
    {
        $this->onQueue('notifications');
    }

    /* After an event: the events of the next WINDOW seconds go out with it */
    public static function soon(): void
    {
        self::dispatch()->delay(now()->addSeconds(self::WINDOW));
    }

    public function handle(Notifier $notifier): void
    {
        $wait = null;
        $ids = NotificationOutbox::whereNull('sent_at')->distinct()->pluck('channel_id');
        foreach (NotificationChannel::whereIn('id', $ids)->orderBy('id')->get() as $channel)
        {
            $after = $notifier->flush($channel);
            if ($after !== null)
                $wait = $wait === null ? $after : min($wait, $after);
        }
        // a chat asked to wait or a delivery failed: the next run then, one waiting at a time; the sync queue of the
        // tests runs a dispatch at once, so no next run there
        if ($wait !== null && !$this->job instanceof SyncJob)
            self::dispatch()->delay(now()->addSeconds($wait));
    }
}

    /** Send what waits for this channel; null when nothing is left to send, else the seconds until the next try (the
        wait a chat asked for, or RETRY_SECONDS after a failed delivery) */
    public function flush(NotificationChannel $channel)
    {
        $rows = NotificationOutbox::with(['cm.project', 'batch'])->where('channel_id', $channel->id)->whereNull('sent_at')
            ->orderBy('id')->get();
        if ($rows->isEmpty())
            return null;
        if (!$channel->enabled)
        {
            NotificationOutbox::whereKey($rows->modelKeys())->update(['sent_at' => now(), 'error' => 'channel turned off']);
            return null;
        }
        $blocked = (int) Cache::get(self::BLOCKED.$channel->id, 0) - now()->getTimestamp();
        if ($blocked > 0)
            return $blocked;

        try
        {
            $sent = false;
            if ($channel->type === 'webhook')
                foreach ($rows as $row)
                {
                    if ($row->cm && $channel->wants($row->event))
                    {
                        $this->sendWebhook($channel, $this->payload($row->cm, $row->event, $row->batch, $this->moduleLine($row->cm, $row->event)));
                        $sent = true;
                    }
                    $row->update(['sent_at' => now()]);
                }
            else
                foreach ($rows->groupBy('batch_id') as $group)
                {
                    $sent = $this->deliverPack($channel, $group) || $sent;
                    NotificationOutbox::whereKey($group->modelKeys())->update(['sent_at' => now()]);
                }
            if ($sent)
                $channel->update(['last_sent_at' => now(), 'last_error' => null]);
            return null;
        }
        catch (\Throwable $e)
        {
            $retryAfter = self::retryAfter($e);
            if ($retryAfter !== null)
            {
                Cache::put(self::BLOCKED.$channel->id, now()->getTimestamp() + $retryAfter, $retryAfter + 60);
                return $retryAfter;
            }
            $error = self::errorText($e, $channel);
            $channel->update(['last_error' => now()->local()->format('Y-m-d H:i').' '.$error]);
            $left = false;
            foreach (NotificationOutbox::whereKey($rows->modelKeys())->whereNull('sent_at')->get() as $row)
            {
                $attempts = $row->attempts + 1;
                $row->update(['attempts' => $attempts, 'error' => $error, 'sent_at' => $attempts >= self::ATTEMPTS ? now() : null]);
                $left = $left || $attempts < self::ATTEMPTS;
            }
            return $left ? self::RETRY_SECONDS : null;
        }
    }

    /* One batch's events in one message: a part per event the channel wants, a module per line. A bot answers in the
       batch's thread, posting its summary first if needed, then edits the summary with the numbers of now, also when
       no part is left. @return bool whether anything was sent */
    protected function deliverPack(NotificationChannel $channel, $rows)
    {
        $batch = $rows->first()->batch;
        $lines = [];
        foreach (['started' => 'started', 'completed' => 'done', 'failed' => 'failed'] as $event => $word)
        {
            $mine = $rows->filter(fn ($row) => $row->event === $event && $row->cm && $channel->wants($event));
            if ($mine->isEmpty())
                continue;
            $lines[] = self::ICONS[$event].' '.$mine->count().' '.$word.':';
            foreach ($mine as $row)
                $lines[] = $this->moduleText($row->cm, $event);
        }

        if ($channel->isThreaded() && $batch)
        {
            $created = false;
            $root = $this->thread($channel, $batch, $created);
            foreach ($this->split($lines) as $text)
                $this->send($channel, $text, $root);
            if (!$created)
                $this->edit($channel, $root, $this->summary($batch));
            return true;
        }

        $first = $rows->first(fn ($row) => $row->cm);
        $prefix = $first ? $this->projectPrefix($first->cm) : '';
        foreach ($this->split($lines) as $text)
            $this->send($channel, $prefix.$text);
        return $lines !== [];
    }

    /* Lines into messages of at most SPLIT characters */
    protected function split(array $lines)
    {
        $messages = [];
        $current = '';
        foreach ($lines as $line)
        {
            if ($current !== '' && mb_strlen($current) + 1 + mb_strlen($line) > self::SPLIT)
            {
                $messages[] = $current;
                $current = '';
            }
            $current = $current === '' ? $line : $current."\n".$line;
        }
        if ($current !== '')
            $messages[] = $current;
        return $messages;
    }

    /* Seconds a chat server asked to wait (HTTP 429), or null for any other failure */
    protected static function retryAfter(\Throwable $e)
    {
        if ($e instanceof RateLimited)
            return $e->retryAfter;
        if ($e instanceof RequestException && $e->response->status() == 429)
            return max(1, ((int) $e->response->header('Retry-After')) ?: 10);
        return null;
    }

    /* At least GAP_MICROSECONDS between two calls to one chat (Telegram: about one message a second in a chat) */
    protected function pace(NotificationChannel $channel)
    {
        $wait = self::GAP_MICROSECONDS - (int) ((microtime(true) - (float) Cache::get(self::LAST_CALL.$channel->id, 0)) * 1000000);
        if ($wait > 0)
            Sleep::usleep($wait);
        Cache::put(self::LAST_CALL.$channel->id, microtime(true), 60);
    }
